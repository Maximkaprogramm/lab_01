# Toolkit (Лабораторная работа 1)
Рабочий калькулятор, выполняющий арифметические операции со множеством числовых выражений, и конвертер различных единиц измерения.

Программа запускается через командную строку (Terminal).


## Калькулятор
- поддержка множества операций:
  - `+` — сложение;
  - `-` — вычитание;
  - `*` — умножение;
  - `/` — деление;
  - `%` — остаток от деления;
  - `//` — целочисленное деление;
- работает с положительными, отрицательными числами;
- вычисляет выражения как с целыми, так и с дробными числами;
- анализирует выражение и учитывает приоритет арифметических операций;
- проверяет корректность введенного выражения;
- вычисляет только корректные выражения любой сложности;
- любые ошибки ввода обрабатываются;

## Конвертер единиц измерения

Доступные единицы измерения: 
- **масса:** `g`, `kg`;
- **температура:** `c`, `k`, `f`.
- **длина:** `mm`, `cm`, `m`, `km`;

Возможности конвертера:

- проверяет корректность введенных единиц измерения;
- учитывает совместимость единиц измерения;
- ошибки некорректных и несовместимых единиц измерения обрабатываются;
- учитывает допустимые границы температуры;
- преобразовывает входное значение;

## Округление результатов

Для вычисления выражений используются числа типа `float`. 

Программа обрабатывает числовые значения по правилу:
1. Округление происходит после всех вычислений, сохраняя точность промежуточных результатов.
2. Результат вычислений округляется по правилу: 
- **если результат выражения равен нулю, то выводится число с 2-мя знаками после точки:**
```text
0 -> 0.00
```
- **если результат выражения из интервала от -0.1 до 0.1 и исходное значение не равно нулю, то выводится число с 10-ю знаками после точки:**

- **дробные и целые числа выводятся с 2-мя знаками после точки:**
```text
11 / 3 -> 3.67
392892.30227392 -> 392892.30
1 mm - m -> 0.00100000
777.123 -> 777.12
```
**Важно:** округление чисел производится засчёт форматирования чисел типа `float`!

***Примечание***: тип `float` хранит двоичную запись числа, поэтому некоторые десятичные числа могут быть представлены с определенной погрешностью вычисления.

## Тестирование

Для автоматической проверки программы используется библиотека `Pytest`. Библиотеку следует установить с остальными зависимостями проекта. Они записаны в файле **requirements.txt**:
```bash
pip install -r requirements.txt
```
Запуск тестов производиться через консоль командой:
```bash
pytest (запускает все тесты программы)
```
Можно запустить определенный файл:
```bash
pytest tests/test_converter.py
```
Подробный вывод тестов:
```bash
pytest -v или pytest -vv (ещё подробнее)
```

**Тесты позволяют проверить**:
- корректность округления результатов;
- использование унарных/бинарных знаков;
- ошибки при неправильном вводе выражения;
- результат арифметического выражения;
- результат перевода из одной единицы измерения в другую;
- работу с маленькими числовыми значениями;
